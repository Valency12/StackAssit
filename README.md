# StockAssist

StockAssist es un programa diseñado para facilitar y automatizar procesos relacionados con el control de inventario.

El sistema ayuda a identificar productos con **stock bajo o agotado** y permite agilizar el proceso de búsqueda de proveedores y generación de **cotizaciones** para reabastecer dichos productos.

La idea principal es reducir el trabajo manual necesario para revisar el inventario, detectar faltantes y preparar las solicitudes de compra correspondientes.

## Ejecución

Clona el repositorio:

```bash
git clone https://github.com/Valency12/StackAssit.git
cd StackAssit
```
Ejecuta el programa:

```bash
python stockassist.py
```

Se requiere tener Python instalado en el equipo.
